React dashboards for an OCT (optical coherence tomography) medical imaging system used in heart procedures.
They showed patient and physician data, heart imaging data, and DICOM images, with filtering. A real-time
monitoring dashboard was used by internal and testing teams.

I built them at Capgemini in React and TypeScript, on top of the Node.js APIs in the OCT data API project.
The code isn't public.
